🎯 Metas & KPIs tiene una función específica. Aquí se definen o aceptan las referencias con las que Finza medirá el desempeño. El análisis de causas, tendencias, proyecciones, escenarios, decisiones y aprendizaje se consulta en 🧠 Inteligencia, evitando mantener la misma información completa en dos lugares.

🎯 Centro de Gestión de KPIs — Fase 2

Finza puede trabajar de dos formas: meta manual, si el empresario desea establecerla, o meta inteligente, calculada automáticamente a partir del histórico disponible y de relaciones económicas verificables. Si aún no existe evidencia suficiente, Finza lo indicará en lugar de inventar una meta.

ℹ️ Referencia única: el desempeño, las anomalías y las variaciones se muestran en Inteligencia. Este espacio queda para definir la referencia de medición.

📊 Desempeño: Real vs Meta vs Presupuesto

🚨 Anomalías y alertas inteligentes

Finza compara el período actual con su período comparable y detecta desviaciones relevantes. No se generan alertas estadísticas cuando no existe una base suficiente.

📈 Variaciones económicas

🧠 Centro de Inteligencia Empresarial — Fase 3

De la desviación a la decisión. Finza analiza los componentes que explican el resultado, separa hechos de inferencias y permite probar escenarios sin modificar los datos reales. La simulación no altera la contabilidad ni el inventario.

🔬 Simulador de escenarios

Modifique porcentajes para responder “¿qué pasaría si...?”. Un valor positivo aumenta el componente; uno negativo lo reduce.

🎯 Decisión sugerida

🧾 Trazabilidad

Las conclusiones de Fase 3 se generan a partir de datos y cálculos existentes. Cuando no exista evidencia suficiente, Finza lo declara expresamente.

🔗 Relaciones entre Indicadores — Fase 3.3

Finza cruza indicadores para detectar relaciones económicas relevantes. Las relaciones son señales cuantificadas, no pruebas de causalidad.

📈 Proyección Empresarial — Fase 3.4

Finza proyecta el próximo período comparable a partir del comportamiento observado. Si la evidencia es insuficiente, no fabrica una previsión.

🎯 Comparador Estratégico de Escenarios — Fase 3.5

De “¿qué pasaría si...?” a “¿qué alternativa conviene más?” Finza compara hasta tres estrategias simultáneamente sin modificar los datos reales. La puntuación es una ayuda cuantitativa, no una orden automática.

🧭 Centro de Decisiones — Fase 3.6

Aquí una señal o escenario puede convertirse en una decisión gestionable. Finza conserva la evidencia, la alternativa considerada, el resultado esperado y el estado de seguimiento. No ejecuta acciones por cuenta propia.

📈 Seguimiento de Resultados — Fase 3.7

Finza compara lo que se esperaba obtener con lo que realmente ocurrió. El seguimiento no cambia los datos contables: registra evidencia para evaluar la decisión.

🧠 Aprendizaje Empresarial — Fase 3.8

De la experiencia al conocimiento. Finza analiza decisiones con resultado real para medir qué tan acertadas fueron sus estimaciones y detectar patrones internos. No convierte un caso aislado en una regla y no afirma causalidad cuando los datos no la demuestran.

🛡️ Motor de Evidencia y Confianza — Fase 3.9

Finza separa lo que sabe de lo que infiere. Cada conclusión se clasifica según su naturaleza, fuente, fundamento y nivel de confianza para evitar confundir hechos, cálculos, relaciones, hipótesis, proyecciones, recomendaciones y aprendizaje.

🌳 Árbol de Decisión Empresarial — Fase 3.1

Finza transforma los indicadores en una secuencia de decisión: síntoma → indicador afectado → componente a investigar → impacto → acción prioritaria → resultado a vigilar. Las causas inferidas se muestran como hipótesis, nunca como hechos confirmados.

🔬 Análisis de Causas y Contribuciones — Fase 3.2

Finza descompone el cambio del resultado entre períodos comparables y cuantifica cuánto aporta cada componente. Una contribución cuantificada no equivale automáticamente a una causa raíz: cuando faltan datos operativos, el sistema indica qué debe investigarse.
